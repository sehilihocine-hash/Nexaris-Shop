NEXARIS SHOP
============

1. Décompresse le fichier.
2. Ouvre index.html dans un navigateur pour tester la boutique.
3. Les produits de démonstration sont dans script.js.
4. Le panier est sauvegardé dans le navigateur.

IMPORTANT
---------
Cette version est une démo front-end : le paiement et l'enregistrement réel des commandes ne sont pas encore connectés.
Pour une vraie boutique, il faudra ajouter un serveur/base de données et un prestataire de paiement.
